
# ArUC Analysis Pipeline
This repository contains a Nextflow pipeline for analysing **ArUC library**.

**Output**: 
```
  - Statistics in Extended Data Fig. 4b (`./data/trinu_acc/`) 
```
    
---

## Quick Start
**Extract test input and output data:**
```bash
tar -xvzf ArUC.tar.gz
```

**Run the pipeline:**
```bash
./bin/nextflow run analysis.nf \
  --bam input/simplex.bam \
  --ref input/reference.fasta \
  --umi_bed input/UMI.bed \
  --ribo_bed input/ribo_trinu.bed \
  --umi_r_for UMI_combining_bases_for.R \
  --umi_r_rev UMI_combining_bases_rev.R  \
  --umi_r_pairing pairing_up_for_rev_UMI+channel.R
```

**Check results from Dorado duplex calling:**
```bash
./bin/samtools view ./input/duplex.bam|cut -f24|sort|uniq -c ;
     21 # number of called duplexes
3041829 dx:i:0 # number of simplex reads
     42 dx:i:-1 # number of reads can be paired into duplexes (21*2)
```

## Required input
The pipeline requires the following:

1. **Basecalls** (generated by [dorado](https://github.com/nanoporetech/dorado) simplex and duplex callers, and indexed by [SAMtools](https://github.com/samtools/samtools))  
    - Formats: `.bam`  
    - Example: `./input/simplex.bam`, `./input/duplex.bam`  

    Generate basecalls as follows:
    ```bash
    # Run dorado simplex caller (GPU recommended)
    dorado basecaller dna_r10.4.1_e8.2_400bps_sup@v4.2.0 <raw_signal_folder> > simplex_basecalls.bam

    # Run dorado duplex caller (GPU recommended)
    dorado duplex dna_r10.4.1_e8.2_400bps_sup@v4.2.0 <raw_signal_folder> > duplex_basecalls.bam

    # Index BAM, generating index files in .bam.bai format
    bin/samtools index <simplex_basecalls.bam>
    ```

2. **Reference fasta** (UMI base as "N", indexed by [SAMtools](https://github.com/samtools/samtools))
    - Formats: `.fasta`  
    - Example: `./input/reference.fasta`

    Needs to be indexed:
    ```bash
    # Generate index in .fasta.fai format
    bin/samtools faidx <reference.fasta> ;
    ```

3. **UMI bed** (bed file to locate the UMI region)
    - Formats: `.bed`  
    - Example: `./input/UMI.bed`

4. **Trinucleotide bed** (bed file to locate the ribo-containing/-opposite trinucleotide region)
    - Formats: `.bed`  
    - Example: `./input/ribo_trinu.bed`

## To reproduce the analysis 
run 
```bash
./bin/nextflow run analysis.nf \
  --bam <basecalls.bam> \ #Input basecalls file
  --ref <reference.fasta> \ #Input reference sequence
  --umi_bed <umi.bed> \ #Input UMI region bed file
  --ribo_bed <ribo_trinu.bed> \ #Input ribonucleotide-containing/-opposite region bed file
  --umi_r_for <UMI_combining_bases_for.R> \ #R script to combine UMI bases in forward reads
  --umi_r_rev <UMI_combining_bases_rev.R>  \ #R script to combine UMI bases in reverse reads
  --umi_r_pairing <pairing_up_for_rev_UMI+channel.R> #R script for duplex pairing using UMI and Channel ID
```
    
e. g. 
```bash
./bin/nextflow run analysis.nf \
  --bam input/simplex.bam \
  --ref input/reference.fasta \
  --umi_bed input/UMI.bed \
  --ribo_bed input/ribo_trinu.bed \
  --umi_r_for UMI_combining_bases_for.R \
  --umi_r_rev UMI_combining_bases_rev.R  \
  --umi_r_pairing pairing_up_for_rev_UMI+channel.R
```
