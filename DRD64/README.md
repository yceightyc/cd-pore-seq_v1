## Quick Start
**Extract input data:**
```bash
tar -xvzf input_data.tar.gz
tar -xvzf input/DRD64.tar.gz
```

**Run the pipeline:**
```bash
./bin/nextflow run analysis.nf \
  --bam input/simplex.bam \
  --ref input/new_masked_ref.fasta \
  --unmaskref input/unmasked_reference_fasta_test10.fasta \
  --rawsignal input/rawsignal/ \
  --rscript plot_ampli_time_perkmer.R \
  --pyscript RF_training_val.py 
```

## Required input
The pipeline requires the following:
1. **Raw signal data** (`.fast5`)  
    - Raw signal from sequencing.  
    - Example: `./input/rawsignal/`

2. **Basecalls** (generated by [dorado](https://github.com/nanoporetech/dorado); BAM converted to FASTQ by [SAMtools](https://github.com/samtools/samtools); raw signal indexed by [f5c](https://github.com/hasindu2008/f5c))  
    - Formats: `.bam`, `.fastq`  
    - Example: `./input/simplex.bam`, `./input/basecalls.fastq`  

    Generate basecalls as follows:
    ```bash
    # Run dorado (GPU recommended)
    dorado basecaller dna_r10.4.1_e8.2_400bps_sup@v4.2.0 <raw_signal_folder> > basecalls.bam

    # Convert BAM to FASTQ 
    samtools fastq -T "*" basecalls.bam > basecalls.fastq

    # Index BAM, generating index files in .bam.bai format
    bin/samtools index basecalls.bam

    # Index raw signals with the FASTQ, generating index files in .fastq.index, .fastq.index.gzi, .fastq.index.readdb, .fastq.index.fai formats
    bin/f5c index -d <raw_signal_folder> basecalls.fastq
    ```

3. **Masked reference fasta** (the trincucleotide masked as "N", used in alignment, indexed by [SAMtools](https://github.com/samtools/samtools))
    - Formats: `.fasta`  
    - Example: `./input/new_masked_ref.fasta`

    Needs to be indexed:
    ```bash
    # Generate index in .fasta.fai format
    bin/samtools faidx <reference_with_trinucleotide_masked_as_N.fasta> ;
    ```

4. **Unmasked reference fasta** (the trincucleotide context defined, used in event-alignment, indexed by [SAMtools](https://github.com/samtools/samtools))
    - Formats: `.fasta`  
    - Example: `./input/unmasked_reference_fasta_test10.fasta`

    Needs to be indexed:
    ```bash
    # Generate index in .fasta.fai format
    bin/samtools faidx <reference_with_trinucleotide_defined.fasta> ;
    ```

## To reproduce the analysis 
run 
```bash
./bin/nextflow run analysis.nf \
  --bam <basecalls.bam> \ #Input basecalls file
  --ref <reference_with_trinucleotide_masked_as_N.fasta> \ #Input reference for alignment file
  --unmaskref <reference_with_trinucleotide_defined.fasta> \ #Input reference for eventalignment file
  --rawsignal <path_to_rawsignal_folder> \ #Input raw signal folder
  --rscript plot_ampli_time_perkmer.R \ #R script for data processing, population-based analysis, visualisation and modeling preparation
  --pyscript RF_training_val.py #Python script for classifier training, validation and visualisation
```
    
e. g.
```bash
./bin/nextflow run analysis.nf --bam input/simplex.bam --ref input/new_masked_ref.fasta --unmaskref input/unmask_reference_fasta_test10.fasta --rawsignal input/rawsignal/ --rscript plot_ampli_time_perkmer.R --pyscript RF_training_val.py
```
