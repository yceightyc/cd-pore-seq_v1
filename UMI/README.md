# UMI Analysis Pipeline
This repository contains a Nextflow pipeline for analysing **UMI library**.

**Output**: 
``` 
  - Statistics in Fig. 3b (`./data/summary_R10.txt` & `./data/summary_HD.txt`)
  - plot_degeneracy.R analyses duplex pairing accuracy, measured by barcode consistency between paired forward and reverse reads, using channel ID and different numbers of UMI bases.
```

---

## Quick Start
**Extract test input data:**
```bash
tar -xvzf UMI.tar.gz
```

**Run the pipeline:**
```bash
./bin/nextflow run analysis.nf \
  --bam_r10 input/R10_simplex.bam \
  --bam_hd input/HD_simplex.bam \
  --ref input/reference.fasta \
  --roi_bed input/barcode_ROI_UMI.bed \
  --fil_barcode_rscript filter_barcode_calls.R \
  --umi_r_for UMI_permut_combining_bases_for.R \
  --umi_r_rev UMI_permut_combining_bases_rev.R \
  --bandu_r_for pull_barcoded_filtered_for.R \
  --bandu_r_rev pull_barcoded_filtered_rev.R \
  --pairing_r pairing_up.R \
  --degen_r UMI_degeneracy_analysis.R \
  --plot_r plot_degeneracy.R
```

## Required input
The pipeline requires the following:

1. **Basecalls** (generated by [dorado](https://github.com/nanoporetech/dorado) simplex and duplex callers, and indexed by [SAMtools](https://github.com/samtools/samtools))  
    - Formats: `.bam`  
    - Example: `./input/R10_simplex.bam`, `./input/R10_duplex.bam`, `./input/HD_simplex.bam`, `./input/HD_duplex.bam`  

    Generate basecalls as follows:
    ```bash
    # Run dorado simplex caller (GPU recommended)
    dorado basecaller dna_r10.4.1_e8.2_400bps_sup@v4.2.0 <raw_signal_folder> > <simplex_basecalls.bam>

    # Run dorado duplex caller (GPU recommended)
    dorado duplex dna_r10.4.1_e8.2_400bps_sup@v4.2.0 <raw_signal_folder> > <duplex_basecalls.bam>

    # Index BAM, generating index files in .bam.bai format
    bin/samtools index <simplex_basecalls.bam>

2. **Reference fasta** (UMI base as "N", and indexed by [SAMtools](https://github.com/samtools/samtools))
    - Formats: `.fasta`  
    - Example: `./input/reference.fasta`

    Needs to be indexed:
    ```bash
    # Generate index in .fasta.fai format
    bin/samtools faidx <reference.fasta> ;
    ```

3. **ROI (region of interest) bed** (bed file to locate the barcode, modification-containing randomers, and UMI regions)
    - Formats: `.bed`  
    - Example: `./input/barcode_ROI_UMI.bed`

## To reproduce the analysis 
run 
```bash
./bin/nextflow run analysis.nf \ 
  --bam_r10 <R10_simplex.bam> \ #Input basecalls from R10 flow cell
  --bam_hd <HD_simplex.bam> \ #Input basecalls from HD flow cell
  --ref <reference.fasta> \ #Input reference sequence
  --roi_bed <barcode_ROI_UMI.bed> \ #Input region of interest bed file
  --fil_barcode_rscript <filter_barcode_calls.R> \ #R script to filter reads without mismatched barcode base
  --umi_r_for <UMI_permut_combining_bases_for.R> \ #R script to combine UMI bases in forward reads
  --umi_r_rev <UMI_permut_combining_bases_rev.R> \ #R script to combine UMI bases in reverse reads
  --bandu_r_for <pull_barcoded_filtered_for.R> \ #R script to fetch the UMIs of barcode filtered forward reads
  --bandu_r_rev <pull_barcoded_filtered_rev.R> \ #R script to fetch the UMIs of barcode filtered reverse reads
  --pairing_r <pairing_up.R> \ #R script for duplex pairing using UMI and Channel ID
  --degen_r <UMI_degeneracy_analysis.R> \ # R script to analyse pairing accuracy using decreased numbers of matched UMI
  --plot_r <plot_degeneracy.R> # R script to plot pairing accuracy using decreased numbers of matched UMI
```
    
i.e.
```bash
./bin/nextflow run analysis.nf \
  --bam_r10 input/R10_simplex.bam \
  --bam_hd input/HD_simplex.bam \
  --ref input/reference.fasta \
  --roi_bed input/barcode_ROI_UMI.bed \
  --fil_barcode_rscript filter_barcode_calls.R \
  --umi_r_for UMI_permut_combining_bases_for.R \
  --umi_r_rev UMI_permut_combining_bases_rev.R \
  --bandu_r_for pull_barcoded_filtered_for.R \
  --bandu_r_rev pull_barcoded_filtered_rev.R \
  --pairing_r pairing_up.R \
  --degen_r UMI_degeneracy_analysis.R \
  --plot_r plot_degeneracy.R
```
