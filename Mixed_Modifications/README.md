
# Mixed Modifications Analysis Pipeline
This repository contains a Nextflow pipeline for analysing **Mixed Modifications library**.

**Output**: 
```  
    - Statistics in Fig. 5b (`./data/more_mods_all.bed`) ;  
    - Statistics in Fig. 5c (`./data/surrounding_mod_acc.tsv`) ;
    - Statistics in Fig. 5d (`./data/mod_basecalls_rate.tsv`) ; 
    - Fig. 5e (PENDING) ;
    - Fig. 6a & Extended Data Fig. 7 (`./data/signal_analysis/*_signal.pdf`) ;
    - Fig. 6b & Extended Data Fig. 8 (`./data/signal_analysis/*_dwell_time.pdf`) ;
    - Extended Data Table 3 (`./data/signal_analysis/signal_stats_table.html`) ;
    - Fig. 6c (`./data/ROC_allmods.pdf`) ;
```
    
---

## Quick Start
**Extract test input and output data:**
```bash
tar -xvzf Mixed_Modification.tar.gz
```

**Run the pipeline:**
```bash
./bin/nextflow run analysis.nf \
  --bam input/simplex.bam \
  --ref input/new_masked_ref.fasta \
  --unmaskref input/unmasked_reference_fasta_test10.fasta \
  --rawsignal input/rawsignal/ \
  --rscript plot_ampli_time_perkmer.R \
  --pyscript RF_training_val.py 
```

## Required input
The pipeline requires the following:

1. **Basecalls** (generated by [dorado](https://github.com/nanoporetech/dorado))  
    - Formats: `.bam`  
    - Example: `./input/bams/SQK-NBD114-96_barcode17.bam`  

    Generate basecalls as follows:
    ```bash
    # Run dorado (GPU recommended)
    dorado basecaller dna_r10.4.1_e8.2_400bps_sup@v4.2.0 <raw_signal_folder> --kit-name SQK-NBD114-96 > <basecalls.bam>

    # Demuxing
    dorado demux --output-dir <output_folder> --no-classify <basecalls.bam> 
    ```

2. **Masked reference fastas** (the modified nucleotide and UMI masked as "N", used in alignment, one fasta file for each modification type, indexed by [SAMtools](https://github.com/samtools/samtools))
    - Formats: `.fasta`  
    - Example: `./input/alignment_fastas/barcode17.fasta`

    Needs to be indexed:
    ```bash
    # Generate index in .fasta.fai format
    samtools faidx <reference.fasta> 
    ```

    Aggregated into a single file for later piling basecalls up:
    ```bash
    cat <fastas> > all.fasta
    samtools faidx all.fasta ;
    ```

3. **ROI (region of interest) bed** (bed file to locate the modifications and UMIs)
    - Formats: `.bed`  
    - Example: `./input/UMIs_mods_oppo.bed`

4. **Annotated Raw Signal** (generated with [f5c](https://github.com/hasindu2008/f5c))  
    - Formats: `.tsv`  
    - Example: `./input/eventalign_all.tsv`  

    Generate as follows:
    ```bash
    # Convert pod5 into blow5 using [blue-crab](https://github.com/Psy-Fer/blue-crab), recommended by f5c
    blue-crab p2s <pod5_directory> -o <real_signal.blow5>

    # Index basecalls.fastq and corrected_alignment.bam with signal.blow5 (GPU recommended)
    samtools fastq -T "*" <all_basecalls.bam> > <all_basecalls.fastq>
    f5c index --slow5 <real_signal.blow5> <all_basecalls.fastq>
    ## <all_basecalls.bam> could be dorado basecalling output, or filtered basecalls in .bam

    # Index filtered alignment.bam by [SAMtools](https://github.com/samtools/samtools)
    samtools index <filtered_alignment.bam> 
    ## <filtered_alignment.bam> is filtered alignments, i. e. (`./data/allmods_filtered_final.bam`)

    # Run f5c eventalignment (GPU recommended)
    f5c eventalign --slow5 <real_signal.blow5> --scale-events --print-read-names --pore r10 --min-recalib-events 20 -r <all_basecalls.fastq> -b <filtered_alignment.bam> -g <refseq.fasta> -o <output_real_sig.tsv>
    ## <refseq.fasta> should contain defined sequence at modifications, using the most frequently called bases currently
    ```

## To reproduce the analysis 
run 
```bash
./bin/nextflow run analysis.nf \
  --bam <basecalls.bam> \ #Input basecalls file
  --ref <reference_with_trinucleotide_masked_as_N.fasta> \ #Input reference for alignment file
  --unmaskref <reference_with_trinucleotide_defined.fasta> \ #Input reference for eventalignment file
  --rawsignal <path_to_rawsignal_folder> \ #Input raw signal folder
  --rscript plot_ampli_time_perkmer.R \ #R script for data processing, population-based analysis, visualisation and modeling preparation
  --pyscript RF_training_val.py #Python script for classifier training, validation and visualisation
```
    
i.e.
```bash
./bin/nextflow run analysis.nf --bam input/simplex.bam --ref input/new_masked_ref.fasta --unmaskref input/unmask_reference_fasta_test10.fasta --rawsignal input/rawsignal/ --rscript plot_ampli_time_perkmer.R --pyscript RF_training_val.py
```
