# Reverse-informed Correction and Model Training Pipeline
This repository contains a Nextflow pipeline for **reverse-informed correction**, **randomer calling accuracy analysis**, **testing signal simulation** and **model training**.

Reverse-informed correction is based on [parasail-python](https://github.com/jeffdaily/parasail-python).

## Quick Start
**Extract test input data:**
```bash
tar -xvzf model_training.tar.gz
```

**Run the pipeline:**
```bash
./bin/nextflow run analysis.nf \
  --bam_ribo input/ribo_filtered.bam \
  --bam_ctl input/control_filtered.bam \
  --ref input/reference.fasta \
  --btdesign input/barcode_tri_design.tsv \
  --roi_bed input/UMIs_randomer_barcode.bed \
  --joinbase_r UMI_permut_combining_bases.R \
  --correct_py correction.py \
  --plot_acc_r plot_randomer_acc.R \
  --tri_design input/contig_tridesign.tsv 
```

**Comparing simulation to the real normal signal:**
```bash
Rscript ./simulation_test.R #Output saved in (`./input/eventalign_ctl/*.pdf`)
```

**Model training and validation (GPU required):**
```bash
cd data/
python ../model_training.py model_input.tsv ../input/contig_centralR.tsv ../input/val_DRD60.tsv ../input/val_UMI.tsv ../input/val_TelN.tsv ../input/promethion_r1 ../input/promethion_r2 #Output saved in (`./output/*.pdf`)
```

## Required input
The pipeline requires the following:

1. **Filtered Basecalls** (generated with Dorado simplex caller, see [dorado](https://github.com/nanoporetech/dorado), and filtered by the pipeline in `../SRICO-TelN/`, indexed by [SAMtools](https://github.com/samtools/samtools))  
    - Formats: `.bam`  
    - Example: `./input/ribo_filtered.bam`, `./input/control_filtered.bam`  

    Generate basecalls for filtering using Dordado as follows:
    ```bash
    # Run dorado simplex caller (GPU recommended)
    dorado basecaller dna_r10.4.1_e8.2_400bps_sup@v4.2.0 <raw_signal_folder> > <simplex_basecalls.bam>

    # Index BAM, generating index files in .bam.bai 
    bin/samtools index <simplex_basecalls.bam>
    ```

2. **Reference fasta** (UMI base as "N", indexed by [SAMtools](https://github.com/samtools/samtools))
    - Formats: `.fasta`  
    - Example: `./input/reference.fasta`

    Needs to be indexed:
    ```bash
    # Generate index in .fasta.fai format 
    bin/samtools faidx <reference.fasta> ;
    ```

3. **Barcode and respective trinucleotide design** (File with the barcode and trinucleotide identity of each class)
    - Formats: `.tsv`  
    - Example: `./input/barcode_tri_design.tsv`

4. **Base information of trinucleotide** (File with the barcode information of each trinucleotide class)
    - Formats: `.tsv`  
    - Example: `./input/contig_tridesign.tsv`

Model training requires sequence-annotated (event-alignment) raw/expected signal:

5. **Annotated Raw Signal** (generated with [f5c](https://github.com/hasindu2008/f5c))  
    - Formats: `.tsv`  
    - Example: `./input/eventalign_ctl/real_sig.tsv`; `./input/promethion_r1/*.tsv`  

    Generate as follows:
    ```bash
    # Convert pod5 into blow5 using [blue-crab](https://github.com/Psy-Fer/blue-crab), recommended by f5c
    blue-crab p2s <pod5_directory> -o <real_signal.blow5>

    # Index basecalls.fastq and corrected_alignment.bam with signal.blow5 (GPU recommended)
    samtools fastq -T "*" <all_basecalls.bam> > <all_basecalls.fastq>
    f5c index --slow5 <real_signal.blow5> <all_basecalls.fastq>
    ## <all_basecalls.bam> could be dorado basecalling output, or filtered basecalls in .bam

    # Index corrected alignment.bam by [SAMtools](https://github.com/samtools/samtools)
    samtools index <reverse_corrected_alignment.bam> 
    ## <reverse_corrected_alignment.bam> is correction output, i.e. `./data/corrected_reads_ribo/*.bam`

    # Run f5c eventalignment (GPU recommended)
    f5c eventalign --slow5 <real_signal.blow5> --scale-events --print-read-names --pore r10 --min-recalib-events 20 -r <all_basecalls.fastq> -b <reverse_corrected_alignment.bam> -g <reverse_informed_refseq.fasta> -o <output_real_sig.tsv>
    ## <reverse_informed_refseq.fasta> is reverse informed reference sequence, i.e. `./data/all_reads_ref_ribo.fasta`
    ```
6. **Annotated Expected Normal Signal** (generated with seq2squiggle [seq2squiggle](https://github.com/ZKI-PH-ImageAnalysis/seq2squiggle) & [f5c](https://github.com/hasindu2008/f5c))  
    - Formats: `.tsv`  
    - Example: `./input/eventalign_ctl/sim_sig.tsv`  

    Generate as follows:
    ```bash
    # Simulate expected normal signal from basecalls using seq2squiggle (GPU required)

    seq2squiggle predict <all_basecalls.fastq> -o <sim_signal.blow5> --read-input --model <R1041-human.ckpt> ;
    ## <all_basecalls.fastq> could be raw or filtered basecalls, see above; <R1041-human.ckpt> is the model provided by seq2squiggle.

    # Index basecalls.fastq copy and corrected_alignment.bam with signal.blow5 (GPU recommended)
    cp <all_basecalls.fastq> <all_basecalls_cp.fastq>
    f5c index --slow5 <sim_signal.blow5> <all_basecalls_cp.fastq>

    # Run f5c eventalignment (GPU recommended)
    f5c eventalign --slow5 <sim_signal.blow5> --scale-events --print-read-names --pore r10 --min-recalib-events 20 -r <all_basecalls_cp.fastq> -b <reverse_corrected_alignment.bam> -g <reverse_informed_refseq.fasta> -o <output_exp_sig.tsv>
    ```

## To reproduce the analysis 
run 
```bash
./bin/nextflow run analysis.nf \ 
  --bam_ribo <ribo_filtered.bam> \ #Input filtered ribo basecalls
  --bam_ctl <control_filtered.bam> \ #Input filtered control basecalls
  --ref <reference.fasta> \ #Input reference sequence
  --btdesign <barcode_tri_design.tsv> \ #Input barcode and trinucleotide info
  --roi_bed <UMIs_randomer_barcode.bed> \ #Input region of interest bed file
  --joinbase_r <UMI_permut_combining_bases.R> \ #R script to integrate bases at ROIs
  --correct_py <correction.py> \ #Python script to do reverse-informed correction 
  --plot_acc_r <plot_randomer_acc.R> \ #R script to plot base accuracy in randomer regions before and after the correction
  --tri_design <input/contig_tridesign.tsv>  #Base information of the trinucleotide of each class
```
    
e. g. 
```bash
./bin/nextflow run analysis.nf \
  --bam_ribo input/ribo_filtered.bam \
  --bam_ctl input/control_filtered.bam \
  --ref input/reference.fasta \
  --btdesign input/barcode_tri_design.tsv \
  --roi_bed input/UMIs_randomer_barcode.bed \
  --joinbase_r UMI_permut_combining_bases.R \
  --correct_py correction.py \
  --plot_acc_r plot_randomer_acc.R \
  --tri_design input/contig_tridesign.tsv 
```
