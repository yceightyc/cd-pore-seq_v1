
# TelN Analysis Pipeline
This repository contains a Nextflow pipeline for analysing **TelN library**.

**Output**: 
```
  - Statistics in Fig. 3d & e (see below) ;  
  - Statistics in Fig. 5b (see below) can be generated by running the pipeline with (`./promethION/simplex_repeat1.bam`) and (`./promethION/simplex_repeat2.bam`) as the "--bam" input, these raw data (~80G) can be accessible upon request ;
  - Statistics in Extended Data Fig. 9 (see below) can be generated by running the pipeline with (`./pol-free/simplex.bam`) and (`./pol-free/refseq.fasta`) as the "--bam" and "--ref" input, respectively.
```

## Quick Start
**Extract test input data:**
```bash
tar -xvzf TelN.tar.gz
```

**Run the pipeline:**
```bash
./bin/nextflow run analysis.nf \
  --bam input/simplex.bam \
  --ref input/reference.fasta \
  --roi_bed input/UMIs_randomer_barcode.bed \
  --acc_r pairing_acc.R \
  --r10_data input/paired_output_R10.tsv \
  --hd_data input/paired_output_HD.tsv \
  --mods_data input/pairing_acc_TelN_moremods.tsv \
  --plot_r plot_acc.R 
```

## Table of Content
1. Input Data (`./input/`)
2. Output saved in (`./data/`)
3. Dependency/softwares required (`./bin/`)
4. Working directory generated by Nextflow, can be ignored (`./work/`)
5. Basecalls and filtered beds from 2 independent SRICO-TelN libraries on fresh PromethION R10 flow cells (`./promethION/`)
6. Basecalls, reference sequence in .fasta format and filtered beds from a Klenow-free CD-pore-seq test library (produced on a fresh MinION R10 flow cell) (`./pol-free/`)

## Required input
The pipeline requires the following:

1. **Basecalls** (generated by [dorado](https://github.com/nanoporetech/dorado) simplex and duplex callers, and indexed by [SAMtools](https://github.com/samtools/samtools))  
    - Formats: `.bam`  
    - Example: `./input/simplex.bam`, `./promethION/simplex_repeat1.bam`, `./promethION/simplex_repeat2.bam`  

    Generate basecalls as follows:
    ```bash
    # Run dorado simplex caller (GPU recommended)
    dorado basecaller dna_r10.4.1_e8.2_400bps_sup@v4.2.0 <raw_signal_folder> > <simplex_basecalls.bam>

    # Index BAM, generating index files in .bam.bai format 
    bin/samtools index <simplex_basecalls.bam>

2. **Reference fasta** (UMI base as "N", indexed by [SAMtools](https://github.com/samtools/samtools))
    - Formats: `.fasta`  
    - Example: `./input/reference.fasta`

    Needs to be indexed:
    ```bash
    # Generate index in .fasta.fai format 
    bin/samtools faidx <reference.fasta> ;
    ```

3. **ROI (region of interest) bed** (bed file to locate the barcode, modification-containing randomers, and UMI regions)
    - Formats: `.bed`  
    - Example: `./input/UMIs_randomer_barcode.bed`

4. **Data from other libraries** 
    - UMI bases of Mixed-Mods reads (TelN-based); Formats: `.tsv`  
    - Example: `./input/pairing_acc_TelN_moremods.tsv`

    - Paired SRICO-UMI reads obtained from R10 and HD flow cells; Formats: `.tsv`
    - Example: `./input/paired_output_R10.tsv`; `./input/paired_output_HD.tsv`

    Generated following the instructions (`../SRICO-UMI/`) & (`../Mixed-Mods/`)

## To reproduce the analysis 
run 
```bash
./bin/nextflow run analysis.nf \ 
  --bam <simplex.bam> \ #Input basecalls
  --ref <reference.fasta> \ #Input reference sequence
  --roi_bed <UMIs_randomer_barcode.bed> \ #Input region of interest bed file
  --acc_r <pairing_acc.R> \ #R script to fetch the UMI bases (3 "N"s) on both strands for each read
  --r10_data <input/paired_output_R10.tsv> \ #Paired duplexes from SRICO-UMI data (R10 flow cell)
  --hd_data <input/paired_output_HD.tsv> \ #Paired duplexes from SRICO-UMI data (HD flow cell)
  --mods_data <input/pairing_acc_TelN_moremods.tsv> \ #UMI bases(3 "N"s) on both strands from Mixed-Mods data (TelN-based)
  --plot_r <plot_acc.R>  #R script to plot the pairing accuracy across the datasets
```
    
i.e.
```bash
./bin/nextflow run analysis.nf \
  --bam input/simplex.bam \
  --ref input/reference.fasta \
  --roi_bed input/UMIs_randomer_barcode.bed \
  --acc_r pairing_acc.R \
  --r10_data input/paired_output_R10.tsv \
  --hd_data input/paired_output_HD.tsv \
  --mods_data input/pairing_acc_TelN_moremods.tsv \
  --plot_r plot_acc.R 
```
